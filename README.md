## Descripción del proyecto

Este proyecto tiene como objetivo desarrollar un dashboard interactivo para analizar el catálogo de Netflix y sus tendencias globales.

A través de diferentes indicadores y visualizaciones, se busca identificar la distribución de películas y series por país, los géneros más frecuentes, los directores con mayor cantidad de títulos y la evolución de los lanzamientos a lo largo de los años.
